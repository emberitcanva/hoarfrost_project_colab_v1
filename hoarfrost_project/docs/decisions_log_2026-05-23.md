## Makkonen

- `input_case_01_numeric_registry.md` должен быть единственным численным источником для `case_01`; значения из `variables_case_01_registry.md` перенесены в него.
- Температурный reset является верным механизмом сброса изморози: при `ta_C > 0` или `T1_C > 0` сбрасываются `H`, `rho_t`, `mass_per_m`.
- Рост толщины: `delta_H = I * delta_tau / rho` для положительного `I`.
- Убыль толщины: отрицательное `I` используется для убыли массы/толщины слоя по аналогичной дискретной схеме.
- Средняя плотность слоя при росте: `rho_t_new = (rho_t_prev * H_prev + rho_new * delta_H_growth) / H_new`.
- Масса льда на метр: `mass_per_m = (pi / 4) * (D^2 - d^2) * rho_t`.
- Диаметр обледенелого цилиндра: `D = d + 2H`.
- В формуле (8) Макконена: `a = 0.032` для `windward`, `a = 0.007` для `leeward`.
- Посекционная схема цилиндра разрешена.
- При подтверждённых температурных условиях reset применяется как сброс изморози.

## Goryachev

- `alpha* = 1 / (A - C^2 / B)`.
- Внешние API принимают углы в градусах; внутри формул Горячева углы переводятся в радианы.
- Формула (2) использует только ветвь `+`.
- Формулы (8)–(11) остаются заглушками до отдельного решения.
- В реализации формулы (12) использовать `9.81` вместо `9.84`.

## Coupling

- Единственный автоматический мост Макконен → Горячев: `q0g = rho_t(t*)`.
- В формуле (12) Горячева использовать `Fg = F`, где `F` рассчитана по формуле (6) Горячева.
- `c` по Горячеву используется только диагностически для сравнения с `H(t*)`, без обратного влияния на Макконена.
- `q0` Горячева не изменять с учётом массы льда из Макконена.
- `t*` задаётся явно как конкретный timestamp.
