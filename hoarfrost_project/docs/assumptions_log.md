# Assumptions log (актуальная версия)

## 1. Общие жёсткие правила

- Не использовать несогласованные дополнительные физические формулы.
- Любая новая формула, изменение существующей формулы или новое соглашение по знакам/единицам:
  - сначала оформляется в явном виде,
  - сопровождается описанием переменных и ссылкой на источник,
  - выносится на подтверждение пользователю,
  - только после подтверждения включается в рабочий реестр и код.
- Не подставлять «типовые» или «разумные» значения параметров без явного разрешения пользователя.
- Не домысливать единицы измерения при неоднозначности, а запрашивать уточнение у пользователя.
- Вся неоднозначная логика должна сопровождаться явным TODO / запросом пользователю, а не молчаливым допущением.

## 2. Формулы Макконена

- Используются только уравнения (1)–(15) из файла `makkonen_equations_corrected.md`.
- В реализации блока `makkonen_model.py` каждая функция `eqX_*` должна строго соответствовать своей формуле из реестра.
- Дополнительные зависимости (например, эвристики отключения обледенения при положительных температурах) допустимы только после явного согласования и отдельной фиксации в `decisions_log`.

## 3. Формулы Горячева

- Используется рабочий реестр формул (1)–(12) из файла `goryachev_formulas_corrected.md`.
- Формулы (2), (4), (6), (12) используются в пользовательской редакции.
- В формуле (2) используется ветвь со знаком «+».
- В формуле (12) величина `q0g` трактуется как плотность изморози (см. раздел о связи с Макконеном).

## 4. Углы и единицы измерения

- Углы `φH`, `φK1`, `φK0` во входных данных задаются в градусах.
- Внутри вычислительных функций допустим перевод градусов в радианы только для тригонометрических функций.
- Код не должен ожидать углы в радианах на внешних интерфейсах (API функций).

## 5. Связь Макконен ↔ Горячев

- Для диагностического сравнения толщин в момент времени `t*`:
  - применяется формула (12) Горячева для толщины стенки ГИО `c`;
  - в этой формуле используется `q0g = rho_t(t*)`, где `rho_t(t*)` — средняя плотность слоя изморози из модели Макконена.
- На текущий момент это единственный подтверждённый «мост» Макконен → Горячев.
- Любые дополнительные связи (например, передача массы льда на единицу длины в виде `Fg` или модификация `q0`) должны быть отдельно согласованы и зафиксированы в `decisions_log`.

## 6. Начальные условия и эволюция изморози

- Начальная масса льда на единицу площади принимается равной 0 в начальный момент времени.
- Начальные значения толщины и плотности слоя могут быть заданы явно (например, `H(t0)`, `rho_t(t0)`), но если явно не заданы, их базовое допущение — отсутствие льда.
- Состояние изморози (толщина `H(t)`, плотность формирующегося льда `rho(t)`, средняя плотность слоя `rho_t(t)`, масса льда на единицу длины) является динамическим:
  - переносится с шага на шаг,
  - не обнуляется автоматически при переходе по времени.
- Автоматическое обнуление состояния льда на каждом шаге **запрещено**.
- Обнуление может происходить только при явно описанном физическом механизме (полное таяние, сброс льда и т.п.), который отдельно согласован с пользователем и зафиксирован в `decisions_log`.

## 7. Разность высот точек подвеса

- Разность высот точек подвеса принята равной 0.
- В расчётах она не учитывается, пока не появится отдельное решение о её введении.

## 8. Блок погрешностей

- Блок погрешности (формулы (8)–(11) Горячева для чувствительностей и ΔF) на текущий момент не используется.
- Параметры `ΔφK`, `ΔφH`, `ΔT` не запрашиваются и не участвуют в расчётах.
- В коде допускается наличие интерфейсных заглушек для чувствительностей, но не их произвольная реализация без согласования.

## 9. Параметры es и alpha*

- По параметру `es` (давление насыщенного пара над льдом):
  - используются только согласованные формулы (см. `decisions_log` и `makkonen_equations_corrected.md`).
- Параметр `alpha*`:
  - не запрашивается как независимый вход,
  - вычисляется по подтверждённой формуле `alpha* = 1 / (A - C^2 / B)`.

## 10. Источники численных данных

- Для тестового кейса `case_01` все численные входные данные (геометрия, механика, метео, константы, начальные условия изморози) берутся из файла `input_case_01_numeric_registry.md`.
- Анкета исходных данных `clean_input_questionnaire.md` используется как шаблон для новых кейсов, но не как источник окончательных чисел.

## 12. Ограничение применения формулы (15) Макконена

- Формула (15): rho = 650 * exp(0.227 * t_s) применяется только при T_s <= 0 °C.
- При T_s > 0 °C:
  - рост изморози считается нулевым (Delta H = 0);
  - новая плотность rho_new не используется для наращивания слоя;
  - состояние H и rho_t не увеличивается за счёт текущего шага.
- Это допущение предотвращает заведомо нереалистичные значения плотности (десятки тысяч кг/м³) при T_s > 0 °C и согласуется с физикой: ледяной слой не растёт при положительной температуре поверхности.

## 13. Численные улучшения ν(T) и решателя T_s

- ν(T) берётся по табличной зависимости ν(ta_C) с линейной интерполяцией.
- solve_surface_temperature решает уравнение (2) по T_s методом бисекции на ограниченном интервале.
- Оба решения считаются «численными улучшениями» и могут быть отменены или заменены без изменения физической постановки моделирования.
