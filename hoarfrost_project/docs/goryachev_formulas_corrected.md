# Реестр формул Горячева (исправленный рабочий вариант)

Источник: автореферат диссертации М.П. Горячева
«Система автоматизированного мониторинга силы тяжения провода воздушных линий электропередач по параметрам кручения и провеса».

Этот файл используется как рабочий эталон для последующего написания кода.

## Формулы

(1)
q0 = q0T / (1 + β * (T1 - T0))

(2)
L0 = (-u ± sqrt(2 * α* * l * q0 * sh(u) + u^2)) / (α* * q0)

u = ln( tg(π/4 + φH / 2) )

(3)
L0T = L0 / (1 + β * (T1 - T0))

(4)
φK0 = φK1 - ( α* * q0T * L0T / (2 * sh(u)) * ( l + L0T * ( ch(u) - (α* * q0T * L0T) / (2 * sh(u)) ) ) ) * ( C / (2 * B) )

(5)
L0g = L0T * (1 + β * (T1 - T0))

(6)
F = ( l + L0g * ch(u) - sqrt( ( l + L0g * ch(u) )^2 - 8 * L0g * ( φK1 - φK0 ) * B / C ) ) / ( 2 * α* * L0g ) * ch(u)

(7)
f = ( ( ch(u) - 1 ) * L0 ) / ( 2 * sh(u) ) + α* * q0 * L0^2 / 8

(8)
SφK = dF(φK) / dφK

(9)
SφH = dF(φH) / dφH

(10)
ST = dF(T) / dT

(11)
ΔF = | dF(φK)/dφK * ΔφK | + | dF(φH)/dφH * ΔφH | + | dF(T)/dT * ΔT |

(12)
c = ( - dпр + sqrt( dпр^2 + 4 * Fg / ( q0g * 9.84 * π * L0g ) ) ) / 2

## Принятые замечания

- Формула (2): под корнем только числитель; деление на (α* * q0) выполняется после корня.
- Формула (4): используется в редакции, присланной пользователем.
- Формула (6): множитель ch(u) вынесен после деления на (2 * α* * L0g).
- Формула (12): используется в редакции, присланной пользователем.

## Примечание для кода

При реализации в Python рекомендуется:
- sh(x) -> sinh(x)
- ch(x) -> cosh(x)
- tg(x) -> tan(x)
- ln(x) -> log(x)
- углы φH, φK1, φK0 хранить в радианах внутри вычислительных функций
- знак ± в формуле (2) выбрать отдельно по физическому смыслу и согласованию с калибровочными данными

В рамках текущих соглашений:
- в формуле (2) используется ветвь со знаком «+»;
- в формуле (12) q0g трактуется как плотность изморози;
- для сравнения толщины с моделью Макконена используется q0g = rho_t(t*).
